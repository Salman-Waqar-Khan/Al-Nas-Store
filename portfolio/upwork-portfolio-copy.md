Laravel Web Developer

## Project description

I developed Al-Nas Store as a responsive e-commerce website for an attar and perfume brand. The project includes a customer-facing storefront, individual product pages, a persistent shopping cart, secure cash-on-delivery checkout, and private order tracking using the order number and customer phone number.

The Laravel backend calculates prices from the database, validates stock during checkout, and protects inventory from overselling with database transactions and row locking. Stock is deducted when an order is placed, restored when an order is cancelled, and safely reserved again if a cancelled order is reopened.

Perfume and attar products support size-based variants, with separate prices, images and stock levels for each size. Customers can select a size before adding a product to the bag or buying it directly. The custom admin dashboard includes secure database-based authentication, product and category management, image uploads, variant and inventory controls, searchable and filterable order management, pagination, order details, and fulfilment status updates.

The interface was created with Tailwind CSS and JavaScript, with responsive layouts designed for desktop, tablet, and mobile use.
